# Organizador-de-Promociones-para-Comercios-Locales
Este proyecto es un sistema desarrollado en Python pensado para ayudar a los comercios locales a organizar sus productos en promoción, fechas límite y difusión.

### ¿Qué permite hacer el sistema?
* **Registrar promociones:** Cargar productos nuevos con su precio y fecha de vigencia.
* **Consultar y buscar:** Ver toda la lista de ofertas disponibles o buscar un producto específico por su nombre.
* **Gestionar el listado:** Modificar precios o fechas, y dar de baja productos cuya promoción ya terminó.
* **Control y consejos:** Revisar qué publicaciones siguen pendientes y acceder a recomendaciones rápidas de publicidad para redes o locales.

### Cómo usarlo
1. Descargá los archivos del repositorio y ejecutá el archivo `main.py` en Python.
2. Navegá por las opciones del menú ingresando el número correspondiente (del 1 al 8).
